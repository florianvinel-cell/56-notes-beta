# 56 notes — bêta

Une note par soir, pendant huit semaines. On raconte sa journée, on la traduit en une note de musique, et peu à peu un ciel se dessine : une constellation par semaine, une mélodie qui n'appartient qu'à soi.

**Ouvrir l'app :** https://florianvinel-cell.github.io/56-notes-beta/

C'est une version d'essai. Tout ce que tu y écris (ta mélodie-clé, tes soirs, tes pensées) reste sur ton appareil, dans ton navigateur : rien n'est envoyé nulle part. Si tu changes d'appareil ou effaces les données de ton navigateur, ton ciel repart de zéro.

## L'installer sur son téléphone

La bêta s'installe comme une vraie app : une icône sur l'écran d'accueil, plein écran, sans barre de navigateur, et elle s'ouvre même sans réseau une fois ouverte une première fois.

- **Android (Chrome) :** ouvrir le lien, puis toucher « Installer » en haut de l'app (ou menu ⋮ → « Installer l'application »).
- **iPhone (Safari) :** ouvrir le lien, toucher le bouton Partager, puis « Sur l'écran d'accueil ».
